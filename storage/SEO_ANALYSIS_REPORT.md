## 🔴 Критические проблемы

### 1. SEO Title идентичен заголовку поста (~99%)

**Проблема:** SEO заголовок полностью копирует заголовок статьи, что снижает уникальность и CTR в поисковой выдаче.

**Пример:**
```
Заголовок: "Данко и Cubetonic презентовали новую песню Берег рай"
SEO Title: "Данко и Cubetonic презентовали новую песню Берег рай"
```

**Решение:** Рерайт заголовка с сохранением ключевых слов:
```
SEO Title: "Новый хит: Данко и Cubetonic представили трек «Берег рай»"
```

### 2. Focus Keyword отсутствует (~85%)

**Проблема:** Нет главного ключевого слова, по которому статья должна ранжироваться.

**Влияние:**
- Невозможно оптимизировать под конкретный запрос
- Сложно отслеживать позиции
- Нет фокуса для контента

**Решение:** AI извлекает главное ключевое слово из контента.

### 3. SEO Keywords пустые (~80%)

**Проблема:** Отсутствуют дополнительные ключевые слова для LSI и семантического ядра.

**Решение:** Генерация 5-7 релевантных keywords через AI.

### 4. OG/Twitter данные пустые (~90%)

**Проблема:** При шаринге в соцсетях отображается неоптимизированный контент.

**Влияние:**
- Меньше кликов из соцсетей
- Непривлекательный вид в ленте
- Потеря трафика

**Решение:** Генерация уникальных og_title, og_description, twitter_title, twitter_description.

### 5. SEO Title слишком длинный (~40%)

**Проблема:** Заголовки более 60 символов обрезаются в SERP.

**Пример:**
```
"Лера Кудрявцева отметила 52-летие: на празднике присутствовали Ирина Дубцова, Валерия и другие звёзды шоу-бизнеса"
(110 символов - обрезается)
```

**Решение:** Сокращение до 50-60 символов с сохранением смысла.

## 🟡 Умеренные проблемы

### 6. SEO Description дублирует excerpt (~60%)

**Проблема:** Описание идентично краткому содержанию статьи.

**Решение:** Переформулировка с добавлением призыва к действию.

### 7. Focus Keyword не в Title/Description (~70%)

**Проблема:** Главное ключевое слово не встречается в заголовке или описании.

**Решение:** Включение focus keyword в seo_title и seo_description.
