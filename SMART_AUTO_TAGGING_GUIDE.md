## 📖 Что это?

**Умное автоматическое тегирование** - это революционная функция, которая не просто создает теги, а **автоматически привязывает их ко всем подходящим статьям**.

### Как это работает:

```
1. Анализ контента → Находит часто встречающиеся слова
2. Выбор тегов → Вы выбираете какие слова станут тегами
3. Создание тегов → Система создает новые теги
4. 🤖 АВТОТЕГИРОВАНИЕ → Система находит все статьи с этими словами
5. Привязка → Автоматически добавляет теги к найденным статьям
```

## 🎯 Алгоритм поиска статей

### Критерии поиска:

Система ищет слово в:
1. **post_title** - заголовок статьи
2. **post_content** - содержимое статьи
3. **post_excerpt** - краткое описание

### Условия:
- Поиск регистронезависимый (LIKE с LOWER())
- Только опубликованные статьи (`post_status = 'publish'`)
- Только посты (`post_type = 'post'`)

### SQL-запрос:
```sql
SELECT ID FROM wp_posts
WHERE post_type = 'post'
  AND post_status = 'publish'
  AND (
    LOWER(post_title) LIKE '%слово%'
    OR LOWER(post_content) LIKE '%слово%'
    OR LOWER(post_excerpt) LIKE '%слово%'
  )
```

### Защита от дубликатов:
- Проверка существующих связей
- Тег не добавляется повторно к одной статье

## ⚙️ Технические детали

### Процесс автотегирования:

```php
1. Создание тега (если не существует)
   ├─ Создать термин в wp_terms
   └─ Создать таксономию в wp_term_taxonomy

2. Поиск статей
   └─ SQL запрос с LIKE по title, content, excerpt

3. Для каждой найденной статьи:
   ├─ Проверить существование связи
   ├─ Если нет → создать связь в wp_term_relationships
   └─ Счетчик++

4. Обновление счетчика тега
   └─ UPDATE wp_term_taxonomy SET count = N
```

### Транзакции:
```php
DB::beginTransaction();
try {
    // Создание тегов
    // Автотегирование
    // Обновление счетчиков
    DB::commit();
} catch (Exception $e) {
    DB::rollBack();
    // Ошибка → все откатится
}
```

## ⚠️ Важные замечания

### Точность поиска:

**✅ Найдет:**
- Слово в заголовке
- Слово в тексте статьи
- Слово в описании
- Разные формы слова (если есть в тексте)

**❌ НЕ найдет:**
- Другие формы слова (музыкант ≠ музыканты)
- Синонимы (певец ≠ музыкант)
- Контекстные совпадения

### Рекомендации:

1. **Используйте базовые формы:**
   - ✅ "музыкант" (найдет "музыкант", "музыканта", "музыкантом")
   - ❌ "музыканты" (может пропустить "музыкант")

2. **Проверяйте предпросмотр:**
   - Смотрите сколько статей найдено
   - Проверяйте примеры статей
   - Убедитесь что они релевантны

3. **Начинайте с малого:**
   - Первый раз: 5-10 тегов
   - Проверьте результат
   - Затем можно больше

## 🆘 Возможные проблемы

### Проблема: Слишком долго выполняется

**Причина:** Много тегов или много статей

**Решение:**
- Создавайте за раз не больше 20 тегов
- Если нужно больше - делайте несколько раз
- Проверьте индексы в БД

### Проблема: Тег добавлен не ко всем статьям

**Причина:** Разные формы слова

**Решение:**
- Используйте базовую форму слова
- Для множественного числа создайте отдельный тег
- Или объедините теги после создания

### Проблема: Слишком много ложных срабатываний

**Причина:** Общее слово

**Решение:**
- Проверяйте предпросмотр
- Не используйте слишком общие слова
- Повысьте минимальную частоту
