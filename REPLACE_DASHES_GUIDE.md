# 🔄 Скрипт массовой замены тире

**Файл:** `replace-dashes.php`  
**Назначение:** Замена длинного тире (—) на короткое тире (-) во всех статьях  
**Статус:** ✅ Готов к использованию

---

## 📋 Описание

Этот скрипт выполняет массовую замену символа длинного тире `—` (em dash, Unicode U+2014) на короткое тире `-` (hyphen-minus, ASCII) во всех опубликованных статьях сайта.

### Что заменяется:
- **Было:** `—` (длинное тире, em dash)
- **Стало:** `-` (короткое тире, дефис)

### Где происходит замена:
- ✅ `post_title` - заголовки статей
- ✅ `post_content` - содержимое статей

## 🛠️ Технические детали

### Системные требования:
- PHP 7.4+
- PDO MySQL
- Laravel framework
- Доступ к базе данных

### Что делает скрипт:

1. **Подключается к БД:**
   - Использует настройки из `.env`
   - Поддерживает socket (MAMP) и TCP подключение

2. **Анализирует данные:**
   - Ищет статьи с `post_type = 'post'`
   - Только опубликованные (`post_status = 'publish'`)
   - Только статьи с символом `—`

3. **Выполняет замену:**
   - Заменяет `—` на `-` через `str_replace()`
   - Обновляет `post_modified` и `post_modified_gmt`
   - Использует транзакцию для безопасности

4. **Обновляет метаданные:**
   - `post_modified` = текущее время
   - `post_modified_gmt` = текущее UTC время

### Ручная замена (если нужно):
```sql
-- В заголовках
UPDATE wp_posts 
SET post_title = REPLACE(post_title, '—', '-'),
    post_modified = NOW(),
    post_modified_gmt = UTC_TIMESTAMP()
WHERE post_type = 'post' 
AND post_status = 'publish'
AND post_title LIKE '%—%';

-- В контенте
UPDATE wp_posts 
SET post_content = REPLACE(post_content, '—', '-'),
    post_modified = NOW(),
    post_modified_gmt = UTC_TIMESTAMP()
WHERE post_type = 'post' 
AND post_status = 'publish'
AND post_content LIKE '%—%';
```

## ❓ FAQ

### Q: Можно ли отменить замену?
**A:** Нет, замена необратима. Поэтому обязательно создайте бекап перед использованием.

### Q: Затрагивает ли скрипт черновики?
**A:** Нет, только опубликованные статьи (`post_status = 'publish'`).

### Q: Что произойдет при ошибке?
**A:** Скрипт использует транзакции. При ошибке все изменения будут отменены (rollback).

### Q: Можно ли запустить скрипт повторно?
**A:** Да, можно. При повторном запуске скрипт не найдет длинное тире и выведет "Длинное тире не найдено".

### Q: Влияет ли скрипт на производительность сайта?
**A:** Нет, скрипт работает отдельно. Во время выполнения сайт доступен.

### Q: Как изменить ключ доступа?
**A:** Отредактируйте строку 22 в файле `replace-dashes.php`:
```php
define('ACCESS_KEY', 'ваш_новый_ключ_2026');
```
