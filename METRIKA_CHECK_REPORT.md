## 🔧 Управление счетчиками

### Через админку:
1. Войдите в админку: `/notaadmin`
2. Перейдите в раздел **"Счетчики"** (доступно только суперадмину)
3. Здесь можно:
   - Добавить новые счетчики (Google Analytics, LiveInternet и т.д.)
   - Изменить позицию (sidebar, footer, header)
   - Включить/выключить счетчик
   - Изменить порядок сортировки
   - Редактировать HTML код счетчика
   - Удалить счетчик

### Через базу данных:
```sql
-- Посмотреть все счетчики
SELECT * FROM counters;

-- Включить/выключить
UPDATE counters SET is_active = 1 WHERE id = 1;

-- Изменить позицию
UPDATE counters SET position = 'header' WHERE id = 1;
```
