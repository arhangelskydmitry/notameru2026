### ШАГ 1: Бэкап текущей версии ⚠️

```bash
# На production сервере
cd /path/to/production
tar -czf backup_$(date +%Y%m%d_%H%M%S).tar.gz \
  app/ resources/ routes/ composer.json
```

### ШАГ 2: Загрузка файлов

#### Способ A: Через FTP/SFTP
```
1. Подключитесь к серверу через FileZilla/WinSCP
2. Загрузите файлы из списка выше
3. Сохраните права доступа (755 для .php, 644 для остальных)
```

#### Способ B: Через Git (если используется)
```bash
git pull origin main
```

### ШАГ 3: Обновление зависимостей

```bash
cd /path/to/production
composer dump-autoload
```

### ШАГ 4: Очистка кеша

```bash
php artisan view:clear
php artisan route:clear
php artisan cache:clear
php artisan config:clear
```

## ⚠️ ЧТО ДЕЛАТЬ ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### Проблема: Ошибка 500
```
1. Проверьте логи: storage/logs/laravel.log
2. Проверьте права доступа к файлам
3. Восстановите из бэкапа при необходимости
```

### Проблема: Белая страница
```
1. Включите отображение ошибок в .env:
   APP_DEBUG=true
2. Перезагрузите страницу
3. Скопируйте текст ошибки
```

### Проблема: Класс не найден
```
1. Выполните: composer dump-autoload
2. Очистите кеш: php artisan cache:clear
3. Проверьте, что файл загружен в правильную папку
```

### Проблема: 404 не работает
```
1. Проверьте, что файл resources/views/errors/404.blade.php загружен
2. Очистите кеш view: php artisan view:clear
3. Проверьте синтаксис файла
```
