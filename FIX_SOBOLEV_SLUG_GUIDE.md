# 🔧 ИСПРАВЛЕНИЕ SLUG СО ЗНАКОМ №

## ❌ ПРОБЛЕМА

```
URL: https://notame.ru/andrej-sobolev-pereizdal-svoi-luchshie-pesni-albom-№1
                                                                           ^^
                                                            Недопустимый символ!
```

**Причина:** Знак `№` недопустим в URL и браузеры его не обрабатывают корректно.

**Решение:** Исправить slug статьи, заменив `№` на дефис `-`.

```

https://notame.ru/fix-sobolev-slug.php?key=notaadmin2025
```

## 🆘 АЛЬТЕРНАТИВНЫЙ МЕТОД (через phpMyAdmin)

Если скрипт не работает:

1. Откройте phpMyAdmin
2. Выберите базу данных
3. Откройте таблицу `wp_posts`
4. Найдите статью по заголовку "Андрей Соболев"
5. В поле `post_name` замените `№` на `-`
6. Сохраните

**SQL-запрос:**
```sql
UPDATE wp_posts 
SET post_name = REPLACE(post_name, '№', '-')
WHERE post_name LIKE '%№%'
AND post_type = 'post';
```

Чтобы избежать таких проблем в будущем:

1. **При создании статей** используйте только:
   - Латиницу (a-z)
   - Цифры (0-9)
   - Дефис (-)

2. **Автоматическая транслитерация:**
   В будущем можно добавить автоматическую очистку slug при сохранении статьи.

3. **Проверка перед публикацией:**
   Убедитесь что slug не содержит спецсимволов.
