## 🔧 Функционал

### Создание Бекапов:
- ✅ Через команду: `php artisan backup:create --type=full`
- ✅ Через веб-интерфейс (AJAX)
- ✅ Автоматически по расписанию (cron)

### Типы Бекапов:
- ✅ **Full** - БД + файлы + конфиг
- ✅ **Database** - только БД (mysqldump)
- ✅ **Files** - только файлы

### Хранение:
- ✅ Локальное хранилище (`storage/app/backups/`)
- ✅ Запись в БД таблицу `backups`
- ✅ Формат: `.tar.gz` архив

### Управление:
- ✅ Список всех бекапов с пагинацией
- ✅ Статистика (всего, завершенных, ошибок, размер)
- ✅ Информация о диске (использовано/свободно)
- ✅ Скачивание бекапов
- ✅ Удаление бекапов
- ✅ Ротация старых бекапов (политика retention)

```bash

```

```bash

```

### 3. Создать Тестовый Бекап:
```bash

```

- Перейти в "Бекапы" в меню

```bash
php artisan schedule:list
```
