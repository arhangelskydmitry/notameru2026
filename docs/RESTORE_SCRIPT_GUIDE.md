## ⚡ Быстрый Старт

### Шаг 1: Установить Секретный Ключ

Откройте `restore-backup.php` и измените строку 21:

```php
// ❌ БЫЛО (небезопасно):
define('RESTORE_SECRET_KEY', 'change_this_to_random_string_2026');

// ✅ СТАЛО (ваш ключ):
define('RESTORE_SECRET_KEY', 'ваш_случайный_ключ_здесь_2026');
```

**Генерация случайного ключа:**
```bash
# Вариант 1: Mac/Linux
openssl rand -base64 32

# Вариант 2: Online
https://www.random.org/strings/
```

## 📋 Параметры URL

| Параметр | Описание | Пример |
|----------|----------|--------|
| `backup` | Имя файла бекапа | `backup_full_2026-01-24_03-00-00.tar.gz` |

## 📊 Что Делает Скрипт

### 1. Preview Mode:
- ✅ Показывает содержимое бекапа
- ✅ Проверяет целостность
- ✅ Показывает что будет перезаписано
- ✅ Безопасно (ничего не меняет)

### 2. Database Mode:
- Распаковывает бекап
- Разархивирует SQL (если сжато)
- Импортирует в БД
- Логирует результат

### 3. Files Mode:
- Копирует файлы из бекапа
- Устанавливает права (755)
- Логирует результат

### 4. Full Mode:
- Выполняет Database + Files
- Полное восстановление

## 🆘 Решение Проблем

### Ошибка: "Доступ запрещен"

**Причина:** Неверный ключ  
**Решение:** Проверьте параметр `key` в URL

---

### Ошибка: "Бекап не найден"

**Причина:** Файл не существует  
**Решение:** 
1. Проверьте имя файла
2. Проверьте что бекап в `/storage/app/backups/`

---

### Ошибка: "Нет прав на запись"

**Причина:** Недостаточно прав  
**Решение:**
```bash
chmod -R 755 storage/
chmod -R 755 public/images/
```

---

### Ошибка импорта БД

**Причина:** Проблемы с mysql  
**Решение:** Проверьте настройки БД в `.env`
