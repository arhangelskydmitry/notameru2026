# Руководство по добавлению ALT и TITLE к изображениям

## 📸 Возможности редактора

Редактор TinyMCE в админ-панели поддерживает полноценную работу с атрибутами изображений, включая `alt` и `title`.

## 🎯 Способы добавления изображений с ALT и TITLE

### Способ 1: Через кнопку "Изображение" (Рекомендуется)

1. **Нажмите кнопку "Изображение"** в панели инструментов редактора
2. **Загрузите изображение** одним из способов:
   - Выберите файл через "Browse"
   - Вставьте URL изображения
   - Используйте медиатеку (кнопка "Browse for an image")
3. **Заполните поля**:
   - **Alternative description (ALT)** - обязательное поле для SEO и доступности
     - Пример: "Фото с концерта группы Иванушки International"
   - **Image title (TITLE)** - всплывающая подсказка при наведении
     - Пример: "Концерт в Кремлевском дворце, 2024"
   - **Image description** - дополнительное описание
4. **Вкладка "Advanced"** (Дополнительно):
   - **Style** - CSS стили для изображения
   - **Border** - рамка
   - **Vertical space** и **Horizontal space** - отступы
   - **Class** - CSS класс (aligncenter, alignleft, alignright)

### Способ 2: Drag & Drop (Перетаскивание)

1. **Перетащите изображение** в редактор
2. Изображение загрузится автоматически
3. **Кликните правой кнопкой** на изображение → "Image"
4. **Добавьте ALT и TITLE** в открывшемся диалоге
5. **Нажмите "Save"**

### Способ 3: Вставка из буфера обмена (Paste)

1. **Скопируйте изображение** (Ctrl+C / Cmd+C)
2. **Вставьте в редактор** (Ctrl+V / Cmd+V)
3. Изображение загрузится автоматически
4. **Кликните правой кнопкой** на изображение → "Image"
5. **Добавьте ALT и TITLE** в открывшемся диалоге
6. **Нажмите "Save"**

## 📋 Рекомендации по заполнению

### ALT (Alternative text)
- **Обязательно для всех изображений**
- **Кратко описывайте содержание** (до 125 символов)
- **Не используйте "изображение", "фото"** - это и так понятно
- **Включайте ключевые слова** если они естественны

**Примеры хороших ALT:**
- ✅ "Певица Света на красной дорожке премии Муз-ТВ"
- ✅ "Группа Краски выступает на фестивале Нашествие"
- ✅ "Николай Трубач в студии звукозаписи"

**Примеры плохих ALT:**
- ❌ "Фото" (не информативно)
- ❌ "IMG_1234.jpg" (техническое имя)
- ❌ "" (пусто - плохо для SEO)

### TITLE (подсказка при наведении)
- **Необязательное поле**, но полезно для UX
- **Дополнительная информация**, которая не поместилась в ALT
- **Источник фото**, если это важно

**Примеры:**
- "Фото: РИА Новости"
- "Концерт в Кремлевском дворце, 15 октября 2024"
- "Источник: пресс-служба артиста"

## 🔧 Технические детали

### Что изменилось в коде

1. **ImageUploadController.php**:
   ```php
   // Теперь принимает параметры alt и title
   'alt' => 'nullable|string|max:255',
   'title' => 'nullable|string|max:255',
   ```

2. **TinyMCE настройки**:
   ```javascript
   image_advtab: true,        // Расширенная вкладка
   image_caption: true,       // Подписи к изображениям
   image_title: true,         // Поле Title
   image_description: true,   // Поле Description
   ```

### Структура загруженного изображения

После загрузки изображение будет иметь HTML:
```html
<img src="/imgnews/2024/11/image-large.webp" 
     alt="Описание изображения" 
     title="Подсказка при наведении"
     width="1920" 
     height="1080">
```

## ✅ Чек-лист для редакторов

Перед публикацией статьи проверьте:

- [ ] У всех изображений заполнен атрибут `alt`
- [ ] ALT-текст информативен и включает ключевые слова
- [ ] При необходимости добавлен `title` с источником фото
- [ ] Изображения имеют правильное выравнивание (по центру, слева, справа)
- [ ] Размер изображений оптимизирован (используется WebP формат)

## 🚀 Преимущества правильных ALT и TITLE

1. **SEO оптимизация**:
   - Поисковики индексируют изображения
   - Улучшается позиция в Google Images и Яндекс.Картинках
   
2. **Доступность (Accessibility)**:
   - Скринридеры озвучивают ALT для незрячих пользователей
   - Соответствие стандартам WCAG
   
3. **Резервный текст**:
   - Если изображение не загрузится, пользователь увидит ALT
   
4. **Дополнительная информация**:
   - TITLE даёт контекст при наведении мыши
