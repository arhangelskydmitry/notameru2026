# Nota Miru — спецификация v0.1

## Пользователи

- **Администратор** — пользователи, доступы, шаблоны пресс-карт
- **Редактор** — статьи, SEO, публикация
- **Корреспондент** — выжимка, черновики (без публикации)

## Экраны macOS-приложения

1. **Лента статей** — фильтр: черновик / опубликовано / отключено
2. **Редактор** — Markdown или WYSIWYG, превью
3. **SEO-панель** — поля + кнопка «Сгенерировать ИИ»
4. **Выжимка** — summary, bullet points, reading time
5. **Пресса** — форма ФИО, СМИ, фото → PDF по шаблону
6. **Настройки** — API-ключ, сайт, учётная запись

## Модель статьи

```json
{
  "id": "uuid",
  "title": "",
  "slug": "",
  "body_html": "",
  "status": "draft|published|disabled",
  "seo": {
    "title": "",
    "description": "",
    "keywords": []
  },
  "summary": "",
  "author_id": "",
  "published_at": null
}
```

## Удостоверение «Пресса»

Поля шаблона:

- ФИО, должность, название СМИ
- Номер удостоверения, срок действия
- Фото 3×4
- QR / ссылка на проверку на сайте

Выход: PDF A6 или CR80 (как карта).

## ИИ-промпты (SEO)

Вход: заголовок + текст статьи + язык `ru`.
Выход JSON: `meta_title`, `meta_description`, `keywords[]`, `slug`, `og_title`, `og_description`.

## Очередность разработки

1. Web API + БД статей (MySQL/SQLite)
2. Web-admin: список + редактор + toggle publish
3. SEO endpoint с ИИ
4. macOS-клиент (SwiftUI) — авторизация + редактор
5. Генератор пресс-удостоверений
