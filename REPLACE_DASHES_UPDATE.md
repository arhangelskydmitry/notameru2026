# 🔄 Обновление скрипта замены тире

## ✅ Исправление: добавлена поддержка post_excerpt

### Проблема
После первой замены в некоторых статьях оставались длинные тире. 

**Причина:** Скрипт обрабатывал только `post_title` и `post_content`, но пропускал поле `post_excerpt` (краткое описание статьи).

**Пример:**
```
Статья: «Мне не 20 и даже не 50»: Филипп Киркоров - о паузе в карьере
URL: /mne-ne-20-i-daze-ne-50-filipp-kirkorov-o-pauze-v-karere-zdorove-i-vozvrashhenii-k-bolsim-sou

✅ post_title: тире заменены
✅ post_content: тире заменены  
❌ post_excerpt: тире ОСТАЛИСЬ (1 шт)
```

---

## 🛠️ Что исправлено

### 1. Обновлена функция `previewChanges()`
- ✅ Добавлено поле `post_excerpt` в SQL запрос
- ✅ Подсчет тире в excerpt: `total_dashes_excerpt`
- ✅ Отображение preview для excerpt
- ✅ Обновлена статистика (5 карточек вместо 4)

### 2. Обновлена функция `replaceAllDashes()`
- ✅ Замена тире в `post_excerpt`
- ✅ Подсчет замененных excerpt
- ✅ UPDATE запрос включает `post_excerpt = :excerpt`

### 3. Обновлен HTML интерфейс
- ✅ Карточка "Тире в описаниях" в статистике
- ✅ Отображение "Описание: X" в списке статей
- ✅ Preview для excerpt в списке статей
- ✅ Обновленная карточка "Всего замен" (включает excerpt)

## 🔍 SQL изменения

### Было (v1):
```sql
SELECT ID, post_title, post_content, post_date 
FROM wp_posts 
WHERE post_type = 'post' 
AND post_status = 'publish'
AND (post_title LIKE '%—%' OR post_content LIKE '%—%')
```

### Стало (v2):
```sql
SELECT ID, post_title, post_content, post_excerpt, post_date 
FROM wp_posts 
WHERE post_type = 'post' 
AND post_status = 'publish'
AND (post_title LIKE '%—%' OR post_content LIKE '%—%' OR post_excerpt LIKE '%—%')
```

### UPDATE запрос (v2):
```sql
UPDATE wp_posts 
SET post_title = :title, 
    post_content = :content,
    post_excerpt = :excerpt,        -- НОВОЕ!
    post_modified = NOW(),
    post_modified_gmt = UTC_TIMESTAMP()
WHERE ID = :id
```
