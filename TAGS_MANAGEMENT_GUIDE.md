## 📖 Введение

Модуль управления тегами предоставляет полноценный инструмент для организации и оптимизации системы тегов на сайте. Теги помогают структурировать контент и улучшают навигацию по сайту.

### Основные возможности:
- ✅ Создание, редактирование и удаление тегов
- ✅ Поиск и фильтрация по критериям
- ✅ Объединение дублирующихся тегов
- ✅ Массовое удаление неиспользуемых тегов
- ✅ Детальная статистика использования
- ✅ Просмотр статей для каждого тега

## 📊 Список тегов

### Описание
Главная страница модуля отображает все теги системы с возможностью поиска, фильтрации и сортировки.

### Информация на странице:

#### **Статистика (верхние карточки):**
- **Всего тегов** - общее количество тегов в системе
- **Активные** - теги, используемые хотя бы в одной статье
- **Одиночные** - теги, используемые только в 1 статье
- **Неиспользуемые** - теги без статей

#### **Таблица тегов:**
| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор тега |
| Название | Отображаемое название тега |
| Slug | URL-часть (например: `/tag/novosti`) |
| Описание | Краткое описание тега |
| Кол-во статей | Количество статей с этим тегом |
| Действия | Редактировать, Просмотр, Удалить |

### Поиск и фильтрация:

**Поиск:**
- Поиск по названию или slug

**Фильтры:**
- Все теги
- Активные (с постами)
- Неиспользуемые (без постов)
- Одиночные (1 пост)

**Сортировка:**
- По названию (А-Я / Я-А)
- По количеству статей
- По ID

## ➕ Создание тега

### Как создать новый тег:

1. На странице списка тегов нажмите **"Создать тег"**
2. Заполните форму:
   - **Название** (обязательно) - основное название тега
   - **Slug** (опционально) - автоматически генерируется из названия
   - **Описание** (опционально) - краткое описание тега
3. Нажмите **"Создать тег"**

### Примеры:

**Пример 1: Простой тег**
```
Название: Новости
Slug: novosti (автоматически)
Описание: Все новостные статьи
```

**Пример 2: Тег с кириллицей**
```
Название: Культурные события
Slug: kulturnye-sobytiya (автоматически транслитерируется)
Описание: —
```

### Автоматическая транслитерация:
Если оставить поле "Slug" пустым, система автоматически создаст slug из названия:
- "Новости" → "novosti"
- "День рождения" → "den-rozhdeniya"
- "Интервью 2024" → "intervyu-2024"

## ✏️ Редактирование тега

### Как редактировать тег:

1. Найдите нужный тег в списке
2. Нажмите кнопку **"Редактировать"** (иконка карандаша)
3. Измените нужные поля
4. Нажмите **"Сохранить изменения"**

### Что можно изменить:
- Название тега
- Slug (будьте осторожны - это изменит URL!)
- Описание

### Дополнительная информация на странице редактирования:
- **Список статей с этим тегом** (до 100 последних)
- Быстрые ссылки на редактирование статей
- Просмотр статей на сайте

---

## 🗑️ Удаление тега

### Удаление одного тега:

1. Найдите тег в списке
2. Нажмите кнопку **"Удалить"** (иконка корзины)
3. Подтвердите удаление

**⚠️ Внимание:**
- При удалении тега все связи со статьями будут удалены
- Это действие необратимо
- Статьи не удаляются, только связи с тегом

### Массовое удаление:

1. Выберите несколько тегов (чекбоксы слева)
2. Нажмите **"Удалить выбранные (N)"**
3. Подтвердите удаление

**Быстрые действия:**
- **Выбрать все** - выбрать все видимые теги
- **Снять все** - снять все выборы
- **Неиспользуемые** - выбрать только неиспользуемые теги

## 🔀 Объединение тегов

### Зачем объединять теги?

Объединение тегов полезно когда:
- Есть дублирующиеся теги (например: "Новости" и "Новость")
- Нужно укрупнить категорию (объединить "Рок" и "Рок-музыка")
- Требуется очистить систему от лишних тегов

### Как объединить теги:

1. Нажмите **"Объединить теги"** на главной странице
2. **Выберите исходные теги** - те, которые нужно объединить (можно выбрать несколько)
3. **Выберите целевой тег** - тег, в который будут объединены все исходные
4. Нажмите **"Предпросмотр"** для проверки
5. Нажмите **"Выполнить объединение"**

### Что происходит при объединении:

```
ДО:
  Тег "Новость" → 15 статей
  Тег "Новости" → 42 статьи
  Тег "News" → 8 статей

ПОСЛЕ (целевой: "Новости"):
  Тег "Новости" → 65 статей
  Теги "Новость" и "News" удалены
```

**Процесс:**
1. Все статьи с исходными тегами переназначаются на целевой тег
2. Дубликаты автоматически удаляются
3. Исходные теги удаляются
4. Счетчик целевого тега обновляется

**⚠️ Внимание:**
- Объединение необратимо!
- Целевой тег не может быть в списке исходных
- Рекомендуется выбирать самый используемый тег как целевой

### Поиск в форме объединения:

**Поиск исходных тегов:**
- Используйте поле поиска для фильтрации списка

**Быстрый выбор:**
- **Выбрать все** - выбрать все видимые теги
- **Снять все** - снять все выборы
- **Неиспользуемые** - выбрать только пустые теги

## 📈 Статистика тегов

### Страница статистики

Доступна по кнопке **"Статистика"** на главной странице.

### Разделы статистики:

#### **1. Общая статистика**
- Всего тегов
- Активные теги
- Одиночные теги
- Неиспользуемые теги
- Самый популярный тег

#### **2. Топ-20 популярных тегов**
Таблица с:
- Рейтингом
- Названием и slug
- Количеством статей (с визуальной шкалой)
- Быстрыми действиями (редактировать, просмотр)

#### **3. Неиспользуемые теги**
Список всех тегов без статей:
- ID, название, slug
- Кнопки редактирования и удаления
- Показано первые 50 (если больше)

**Рекомендация:** Регулярно удаляйте неиспользуемые теги для поддержания чистоты системы.

#### **4. Теги с одной статьей**
Список тегов, используемых только в 1 статье:
- Могут быть кандидатами на объединение
- Или на удаление, если не планируется развитие темы

### Структура базы данных

**Таблица: wp_terms**
| Поле | Тип | Описание |
|------|-----|----------|
| term_id | BIGINT | ID термина (PK) |
| name | VARCHAR(200) | Название |
| slug | VARCHAR(200) | URL slug (unique) |

**Таблица: wp_term_taxonomy**
| Поле | Тип | Описание |
|------|-----|----------|
| term_taxonomy_id | BIGINT | ID таксономии (PK) |
| term_id | BIGINT | Ссылка на wp_terms |
| taxonomy | VARCHAR(32) | 'post_tag' для тегов |
| description | LONGTEXT | Описание |
| parent | BIGINT | Родитель (0 для тегов) |
| count | BIGINT | Количество постов |

**Таблица: wp_term_relationships**
| Поле | Тип | Описание |
|------|-----|----------|
| object_id | BIGINT | ID поста |
| term_taxonomy_id | BIGINT | ID таксономии |
| term_order | INT | Порядок |

## 💡 Рекомендации по работе

### Лучшие практики:

1. **Регулярная очистка:**
   - Раз в месяц проверяйте неиспользуемые теги
   - Удаляйте или объединяйте теги с 1 статьей

2. **Именование тегов:**
   - Используйте единый стиль (с заглавной или без)
   - Избегайте дублирования (Новость / Новости)
   - Используйте общепринятые термины

3. **Объединение тегов:**
   - Выбирайте наиболее используемый тег как целевой
   - Делайте предпросмотр перед объединением
   - Документируйте крупные изменения

4. **Slug тегов:**
   - Оставляйте автогенерацию для новых тегов
   - Не меняйте slug у популярных тегов (это изменит URL!)
   - Используйте короткие понятные slug

5. **Статистика:**
   - Отслеживайте топ-20 тегов
   - Используйте популярные теги в новых статьях
   - Анализируйте теги-одиночки

## 🆘 Решение проблем

### Проблема: Не могу удалить тег

**Решение:**
- Убедитесь, что у вас права суперадмина или главреда
- Проверьте, что вы подтверждаете удаление в диалоге
- Проверьте логи Laravel: `storage/logs/laravel.log`

### Проблема: После объединения теги не удалились

**Решение:**
- Объединение выполняется в транзакции
- Если есть ошибка - откат автоматический
- Проверьте логи: `storage/logs/laravel.log`
- Попробуйте объединить меньше тегов за раз

### Проблема: Slug не генерируется автоматически

**Решение:**
- Убедитесь, что оставили поле "Slug" пустым
- Транслитерация работает только при создании
- При редактировании slug нужно указывать вручную

### Проблема: Статистика показывает неверные данные

**Решение:**
- Счетчики обновляются автоматически при изменениях
- Если данные устарели - пересохраните несколько статей
- Обратитесь к разработчику для пересчета
