# 🔍 Анализ контента и автоматическое предложение тегов

**Дата добавления:** 2026-01-25  
**Версия:** 1.1  
**Статус:** ✅ Готово к использованию

---

## 📖 Описание

Функция автоматического анализа контента и предложения новых тегов позволяет:
- Анализировать содержимое статей
- Выявлять наиболее часто встречающиеся слова
- Исключать стоп-слова и существующие теги
- Предлагать новые релевантные теги для создания

---

## 🎯 Как это работает

### 1. **Анализ контента**
Система анализирует:
- `post_title` - заголовки статей
- `post_content` - содержимое статей
- `post_excerpt` - краткие описания

### 2. **Обработка текста**
- Удаление HTML-тегов
- Удаление специальных символов
- Приведение к нижнему регистру
- Разбивка на отдельные слова

### 3. **Фильтрация**
Исключаются:
- Короткие слова (< 4 символов)
- **Стоп-слова** (~400 слов): предлоги, местоимения, союзы и т.д.
- **Существующие теги** - чтобы не создавать дубликаты
- Слова с частотой ниже порога

### 4. **Результат**
Список слов, отсортированных по частоте встречаемости, готовых стать тегами.

### Параметры анализа

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| **Количество статей** | 200 | Сколько последних статей анализировать (50-2000) |
| **Минимальная частота** | 10 | Слово должно встретиться минимум N раз |
| **Топ результатов** | 100 | Сколько слов показать в результатах |

## 📊 Интерфейс

### Статистика
Показывается в верхней части страницы:
- **Статей проанализировано** - сколько статей обработано
- **Найдено слов** - уникальных слов после фильтрации
- **Стоп-слов исключено** - количество исключенных общих слов
- **Существующих тегов** - сколько тегов уже есть в системе

### Таблица результатов
Для каждого слова показано:
- **#** - позиция в рейтинге
- **Слово** - предлагаемый тег
- **Частота** - сколько раз встретилось
- **Визуализация** - progress bar для наглядности

### Функции

**Поиск:**
- Живой поиск по словам
- Фильтрация результатов в реальном времени

**Выбор тегов:**
- Чекбоксы для выбора
- **Выбрать все** - выбрать все видимые
- **Снять все** - снять все выборы
- **Топ-20** - выбрать 20 самых популярных

## ✅ Создание тегов

### Шаг 1: Выбор слов
1. Отметьте чекбоксами слова, которые хотите превратить в теги
2. Счетчик покажет количество выбранных
3. Кнопка "Создать выбранные теги" активируется

### Шаг 2: Подтверждение
1. Нажмите "Создать выбранные теги (N)"
2. Подтвердите действие в диалоге

### Шаг 3: Результат
- Система создаст новые теги
- Автоматически сгенерирует slug
- Пропустит слова, которые уже есть в тегах
- Покажет результат: создано / пропущено

## 🔧 Технические детали

### Стоп-слова

Система исключает **~400 стоп-слов**, включая:

**Русские:**
- Предлоги: без, для, на, над, от, по, про, с, у, через...
- Местоимения: я, ты, он, она, мы, вы, они, что, кто...
- Союзы: и, а, но, или, если, когда, чтобы...
- Частицы: не, ни, же, ли, бы...
- Общие слова: быть, есть, был, будет, был, года, день...

**Английские:**
- the, and, for, with, this, that, have, from...

### Алгоритм обработки

```
1. Получить последние N статей
2. Для каждой статьи:
   - Извлечь текст (title + content + excerpt)
   - Удалить HTML
   - Удалить спецсимволы
   - Разбить на слова
3. Для каждого слова:
   - Проверить длину (>= 4 символа)
   - Проверить стоп-слова
   - Проверить существующие теги
   - Увеличить счетчик
4. Отфильтровать по минимальной частоте
5. Отсортировать по убыванию частоты
6. Взять топ N результатов
```

### Производительность

**Скорость анализа:**
- 100 статей: ~1-2 секунды
- 500 статей: ~5-7 секунд
- 1000 статей: ~10-15 секунд
- 2000 статей: ~20-30 секунд

**Рекомендуется:**
- Не анализировать больше 2000 статей за раз
- При медленной работе уменьшить параметры

## 📝 SQL-запросы

### Получение статей для анализа:
```sql
SELECT post_title, post_content, post_excerpt
FROM wp_posts
WHERE post_type = 'post' 
  AND post_status = 'publish'
ORDER BY post_date DESC
LIMIT 200;
```

### Создание нового тега:
```sql
-- 1. Создаем термин
INSERT INTO wp_terms (name, slug) 
VALUES ('Название', 'nazvanie');

-- 2. Создаем таксономию
INSERT INTO wp_term_taxonomy (term_id, taxonomy, description, parent, count)
VALUES (LAST_INSERT_ID(), 'post_tag', '', 0, 0);
```

## 🆘 Возможные проблемы

### Проблема: Анализ занимает слишком много времени

**Решение:**
- Уменьшите количество статей (100-200)
- Увеличьте минимальную частоту (20-30)
- Уменьшите топ результатов (50)

### Проблема: Много нерелевантных слов

**Решение:**
- Увеличьте минимальную частоту
- Проверьте список стоп-слов
- Вручную отфильтруйте результаты

### Проблема: Слишком мало результатов

**Решение:**
- Увеличьте количество анализируемых статей
- Уменьшите минимальную частоту
- Увеличьте топ результатов

### Проблема: Дубликаты с существующими тегами

**Решение:**
- Система автоматически пропускает существующие теги
- Сообщение покажет: "пропущено (уже существуют): N"

## 📈 Метрики эффективности

**Хорошая статистика:**
- Из 100 предложенных создано 20-30 тегов
- 80%+ созданных тегов активно используются
- Анализ проводится 1-2 раза в месяц

**Признаки проблем:**
- Создается < 10 тегов из 100 предложенных
- Большинство созданных тегов не используются
- Нужно пересмотреть параметры анализа
