### **Как работает автозагрузка:**

```javascript
1. Загружаем первые 12 постов
2. Создаем Intersection Observer
3. Наблюдаем за триггером внизу страницы
4. Когда триггер попадает в viewport:
   - Делаем AJAX запрос
   - Загружаем еще 12 постов
   - Добавляем в ленту
   - Повторяем до конца
```

---

### **API для автозагрузки:**

```
GET /api/posts?offset=12&limit=12

Response:
{
  "posts": [
    {
      "ID": 12345,
      "post_title": "Заголовок",
      "post_name": "slug",
      "post_date": "2026-01-25",
      "post_excerpt": "Описание",
      "thumbnail": "/path/to/image.jpg"
    },
    ...
  ]
}
```

**Эндпоинт уже существует** в `FrontendController::loadMorePosts()`
